# Changelog

## 2.0.0 — 2026-11-10

- Publish the MATLAB 2-adic local-search implementation for rooted
  Camin–Sokal parsimony inference.
- Add a single public `twoALSCS` entry point.
- Include exact single-column and allelic-state column-pair neighborhoods.
- Include shared exact collision lookup and compressed 2-adic radix trees.
- Add serial and process-parallel execution, replayable accepted moves, a
  deterministic example, and release tests.
